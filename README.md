# UniCalcMedical

UniCalcMedical provides reliable, independently implemented code for a range of medical calculators and screening questionnaires used in clinical practice and education. The project is collaboratively maintained by current and former students from University College London, King's College London, and Université Claude Bernard Lyon 1, and aims to offer clear, well-sourced reference implementations for clinicians, students, and developers.

**Live site:** https://oliver-md.github.io/UniCalcMedical/

## What's here

Each calculator is a self-contained, dependency-free HTML page under [`/tools`](./tools). Every tool lists its primary source (original publication, professional body, or public-domain instrument) directly on the page, and cross-references an established reference calculator (e.g. MDCalc) where one exists, so results can be independently verified.

## Scope and disclaimer

These are reference implementations of published clinical scoring systems and screening instruments. They are provided for educational and informational use. They are not a medical device, are not intended for clinical diagnosis or patient care decisions, and should not replace independent clinical judgement or validated institutional tools. See the disclaimer on each individual calculator page for details.

## Contributing

Contributions, corrections, and citation fixes are welcome via pull request. Please include a source citation for any new calculator or any change to an existing formula or cut-off value.
